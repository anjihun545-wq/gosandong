# 고산동, 우리가 담다 — Mobile SPA

고산동 주민자치회 프로젝트용 정적 SPA입니다.

## 배포
GitHub 저장소 루트에 이 폴더의 내용을 그대로 업로드한 뒤 GitHub Pages를 활성화하면 됩니다.
별도 빌드 과정이나 패키지 설치가 필요 없습니다.

## 구성
- `index.html` : 메인 SPA
- `assets/` : 고산동 지도 및 활동 이미지
- `downloads/gosan-map.pdf` : 다운로드용 PDF

## 디자인
원본 PDF의 민트·그린·아이보리 톤앤매너를 유지하면서, 카드/그리드/타이포 위주의 스타트업 스타일로 재구성했습니다.
